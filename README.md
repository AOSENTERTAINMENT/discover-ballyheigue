# Discover Ballyheigue (sample site)

Five-page static tourism site for Ballyheigue, Co. Kerry, on the Wild Atlantic Way.
Content and ideas from @discoverballyheigue on Instagram, Tripadvisor and Google Maps. Aerial footage by AOS Entertainment.

- `build.py` generates the five HTML pages. Edit content there and run `python3 build.py`.
- Drone clips and poster frames live in `assets/drone/`.
- Deployed on Vercel as a static site (no build step).
